# 네 표본의 주요 구성품·규격 귀속 검토

2026-10-20. 저장된 kordoc 파싱 결과를 재사용했다. OCR과 외부 모델 API는 실행하지 않았다.
의미 판단은 Codex가 수행하고, 코드는 저장·구조 검사·목록 대조를 수행했다.

이후 [코드 정리](pipeline_cleanup_2026_10_20.md)로 예전 단계별 모듈과 테스트를 제거했다.
이 문서의 테스트 개수는 정리 전 기록이며 현재 코드의 검증은 정리 결과와 구별한다.

## 주요 목록 결과

| 문서 | 주요 구성 단위 | 최신 사용자 검토 목록과의 차이 |
|---|---:|---|
| 환경감시 및 제어 모니터링 장치 | 4 | 누락·추가 없음 |
| 액체크로마토그래프 질량분석기 | 9 | 누락·추가 없음 |
| 농기계 정적상태·주행성능 분석시험장치 | 10 | 누락·추가 없음 |
| 동물이송진료용 특수차량 | 5 | 누락·추가 없음 |

사용자 파일은 `명확한 정답은 아님`으로 표시된 검토안이다. 현재 파일의 차량 5개를
사용했고, 원본 파일은 수정하지 않았다. 이전 차량 0개·총 23개 기록은 최신 기준이 아니다.
지금은 총 28개다. 주요 목록의 항목 수와 실제 납품 수량은 다르다.

정답을 이미 본 네 개발 표본이므로 **이 일치를 신규 문서의 Precision·Recall로
발표할 수 없다.** 평가 JSON의 비율은 이 검토 목록에 대한 일치율이다. 같은 Codex의
원문 검토이며 독립 의미 평가나 새 표본 일반화 검증이 아니다.

## 두 번의 검토에서 바뀐 점

| 구분 | 1차 | 2차 |
|---|---|---|
| 주요 구성 단위 | 28 | 28 유지 |
| 전체 대상 레코드 | 32: 완성품 4개 포함 | 57: 세부 대상·외부 참조·서비스 포함 |
| 대표 규격 관찰 | 없음 | 27 |
| 후반 검수 표 연결 | 미연결 | 농기계 각 장비에 연결 |
| 외부 장비 구별 | 목록에 추가하지 않았으나 별도 기록 부족 | 케이지·의료장비·산소통·시험대상 역할 기록 |

2차에서는 전력 아래 인버터·콘센트·외부전원을, 수술공간 아래 수납·작업면·조명을
보존했다. PC의 RAM·SSD·HDD는 데이터 처리 시스템 아래에 두었다. 단순히 주요
구성품 개수를 늘리거나 줄이는 개선이 아니라, 규격의 실제 소유 대상을 보완한 것이다.

인버터 정격출력, 진료대 하중·크기, 조명 조도, 작업면 크기, 펌프·주입기의 압력,
서로 다른 카메라의 촬영속도 등을 원문 인용과 연결했다. 수납부의 `권장 치수`와
`기본으로 제작`의 충돌은 필수 수치로 확정하지 않았다.

## 의도적인 오류를 넣어 확인한 한계

| 잘못된 제안 | 구조 검사 | 추가 확인 |
|---|---|---|
| 진료대 및 연결 관찰 삭제 | 통과 | 목록 대조가 누락 1개 검출 |
| 전력시스템 이름을 수냉장치로 변경 | 통과 | 목록 대조가 추가 1개·누락 1개 검출 |
| 인버터 수치를 외부 케이지에 연결 | 거부 | 외부 참조는 요구조건 소유자가 될 수 없음 |
| 차량 범위를 넓힌 뒤 인버터 수치를 차량에 연결 | 통과 | 목록 대조도 검출하지 못함. 의미 검토 필수 |

마지막 사례처럼 인용과 범위가 맞아도 의미 귀속은 틀릴 수 있다. 그래서
`semantic_review_status=pending`, `automatic_compliance_ready=false`를 유지한다.
검사 통과를 학습 라벨 승인이나 제품 적합성 판정으로 사용하지 않는다.
