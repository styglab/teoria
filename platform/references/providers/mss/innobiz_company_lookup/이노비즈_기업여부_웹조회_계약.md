# 이노비즈 기업 여부 웹 조회 계약

## 출처와 의미

- 공식 화면: `https://www.innobiz.net/`
- 제공기관: 중소벤처기업부
- 배포 화면: 중소기업기술혁신협회 이노비즈 인증시스템
- 확인일: 2026-08-06
- 계약 성격: 공식 화면이 사용하는 비로그인 HTML 조회 계약

공식 화면은 기업명 또는 사업자등록번호로 이노비즈 기업 여부와 인증기간을 확인할 수
있다고 안내한다. 별도 공개 OpenAPI 명세가 아니라 공식 HTML과 JavaScript 요청 코드를
대조한 계약이므로 화면 구현 변경 시 예고 없이 바뀔 수 있다.

## Operation

- Method: `GET`
- Path: `/ajax.fill_com.asp`
- 인증: 없음
- CAPTCHA: 관측되지 않음
- 요청 파라미터: `Co_Name` (기업명 또는 사업자등록번호)
- 응답 content type: `text/html`

응답의 `table.table_list_style1` 본문은 다음 열을 제공한다.

| 순서 | 원본 열 | Registry 필드 | 관측 타입 |
|---:|---|---|---|
| 0 | 기업명 | `company_name` | string |
| 1 | 대표자 | `representative_name` | string |
| 2 | 지역 | `region` | string |
| 3 | 관련업종(평가지표) | `industry` | string |
| 4 | 인증유효기간 | `certification_period` | string |

기업 홈페이지 열은 조회 결과의 인증 판정과 무관하고 값이 URL이 아닌 `바로가기` 링크로
표시되므로 구조화 레코드에서 제외했다. 사업자등록번호로 검색할 수 있지만 결과 표에는
사업자등록번호가 다시 표시되지 않는다.

## 검증 관측과 제한

공개 기업명 검색에서 복수 레코드와 `YYYY-MM-DD ~ YYYY-MM-DD` 형식의 인증유효기간을
확인했고, 결과가 없는 검색은 같은 표의 빈 본문을 반환했다. 현재 인증 여부는 조회 결과의
존재만으로 판단하지 않고 조회일이 인증유효기간에 포함되는지 확인한다.
