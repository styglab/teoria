# Kory Parser 변경 이력

실제 적용한 파서 업데이트를 최신 버전부터 기록한다. 각 항목에는 날짜, 문제와 바뀐 동작,
검증·비교 결과, 제한과 배포 상태를 남긴다. 새 수정이 없는 평가 실행은 버전을 올리거나
새 릴리스 항목을 만들지 않고 해당 사이클의 최종 보고서에 기록한다.

## 0.9.17 — 2026-11-10

- PDF 표의 굵은 이중 머리글 구분선을 빈 행으로 읽던 문제를 수정했다. 양옆의 행 구분선과
  내부 세로선을 확인하고, 이중선보다 얇은 행 구분선이 있는 경우 하나의 경계로 처리한다.
  굵은 외곽선도 허용하며 동일 굵기의 얇은 빈 행과 더 넓은 간격은 유지한다.
- 공개 수도용 강관 시방서에서 원문 3행·5열과 5행·2열 표를 각각 4행·5열과
  6행·2열로 읽던 것을 바로잡았다. 원문 렌더링과 선 좌표로 정답을 확인했다.
- 회전·선 간격·굵은 외곽선·실제 빈 행 보존을 검증하는 회귀 검사 9개를 추가했다.
  기존 검사 386개와 새 검사 9개를 통과했다. 새 합성 원문 정답 2개도 통과했다.
- 새 실문서 6개에서 기존 Kory·후보·kordoc 4.22.15를 비교했다. 모두 6/6 처리에 성공했고,
  HWPX 원문 조각 828개와 XLSX cached 값 243개는 보존했다. 새 고정 회귀 원문 3개와
  이전 사이클 문서 6개는 버전 표기를 제외한 출력을 유지했다.
- 같은 호스트에서 warm-up 1회 후 3회 중앙값의 문서별 합계는 기존 2.8046초,
  후보 2.7888초, kordoc 3.4259초였다. 기존 대비 차이는 작아 속도 개선으로 일반화하지 않는다.
  OCR·메모리·전체 본문 정확도는 평가하지 않았다. 과거 160개 회귀셋의 복원 결과도 아니다.
- 자동 Codex 수정 실행기는 namespace 권한 오류로 종료되어 후보를 직접 수정한 뒤
  같은 외부 평가·회귀·채택 gate를 통과해 로컬 소스에 반영했다. 비교 후보의 버전은
  0.9.16으로 동결했으며, 채택 후 배포 메타데이터를 0.9.17로 올렸다.
- GitHub·PyPI 게시와 운영 Worker 재배포는 수행하지 않았다. 실문서·측정값·판정·소스 hash와
  동결 후보는 별도 평가 작업 공간의 로컬 보고서에 보존한다.

## 0.9.16 — 2026-11-01

- XLSX의 셀 밖 텍스트 상자와 그룹 도형에 있는 텍스트 누락을 복구했다. 셀 값과 격자는
  유지하고 도형 텍스트는 별도 문단으로 제공하며, 원본 DrawingML part와 shape ID를 남긴다.
- 셀 내용 없이 도형 텍스트만 있는 시트도 읽는다. 숨긴 도형·그룹은 제외하고 외부 도형
  링크는 가져오지 않는다. 줄바꿈·문단 순서와 중첩 제한을 검증한다.
- 새 회귀 테스트 9개를 포함한 381개 테스트가 통과했다. 가구 규격서의 원문 도형 텍스트
  점검은 기존 Kory·kordoc의 2/6에서 6/6으로 개선됐고 기존 셀 값 736개는 모두 보존했다.
- 최초 비교는 실제 문서 22개에서 진행했다. 고정 회귀 160개 중 1개에 표지 제목과 도형
  문단 3개가 추가돼 자동 게이트는 출력 동일성 조건으로 거절했다. 기존 블록 삭제가 없음을
  확인한 뒤 사용자의 명시적인 반영 지시로 적용했다. 기존 거절 기록은 그대로 보존했다.
- wheel·소스 배포본을 빌드했고, 별도 배포 요청에 따라 로컬 규격서 Worker에 설치했다.
  실행 컨테이너의 버전과 실제 XLSX 파싱을 확인했다. PyPI 게시와 원격 운영 배포는 하지 않았다.
- 전체 형식의 품질 우위나 OCR 개선을 뜻하지 않는다. 후속 18개 문서 평가는 새 코드 변경이
  없어 같은 버전을 유지했다. 비교 요약과 판정·hash는 로컬 사이클 보고서에 보존한다.
