# 보류한 첨부파일·입찰요건 기능

2026-10-16 사용자 결정으로 다음 기능을 현재 제품과 배포에서 제거했다.

- 입찰 첨부파일 발견·다운로드·Object Storage 저장 및 보존기간 삭제
- PDF·HWP·HWPX·Office·ZIP 파싱과 문서 구간 생성
- 문서/API 정보의 참가요건·참여 유의사항 추출, 보정·조건식 구성
- 공고 요건 조회와 업체별 단건·일괄 참가자격 판단
- 해당 Prefect Deployment, AI Worker, 관리자 API, Registry, Skill과 검증 기록

이 디렉터리는 원래 저장소 경로를 유지한 보관본이다. 전용 파일은 이동했고,
공고 수집·Registry 로딩·배포처럼 다른 기능과 섞여 있던 파일은 변경 전 사본을
보관했다. 사본 전체를 현재 소스 위에 덮어쓰면 유지 중인 기능도 되돌릴 수 있다.
보관본은 실행·배포·패키징·현재 테스트 대상이 아니며 문서의 상대 링크와 실행
명령은 당시 기준이다. 복원을 위한 지원 패키지나 호환 import는 제공하지 않는다.

공고·계약·낙찰·개찰·업종 수집과 API 면허·지역 정보 적재, 기업 정보 조회와
시장 분석은 현재 프로젝트에 남긴다. API 응답의 원본 wire 필드도 보존한다.
영속적인 업무 개념인 Published Ontology와 기존 Runtime artifact는 수정하지 않는다.
새 Runtime 배포에는 현재 활성 Registry로 만든 새 artifact를 사용해야 한다.

이미 적용한 SQL migration은 원래 위치에 이력으로 유지한다. 기존 DB의 문서·추출
결과와 Object Storage 객체·인증 volume은 삭제하지 않는다. 활성 Prefect 서버에
남은 관련 Deployment와 예약 실행도 제거해야 중단이 완료된다.

재개하려면 기능 범위·계약·의존성·보안·배포를 다시 검토하고, 현재 저장소 구조와
테스트에 맞게 필요한 부분만 이관한다. 자동 재활성화하지 않는다.

보관된 테스트 파일은 자동 수집을 막기 위해 `.py.txt` 확장자를 사용한다.
내용은 보존하며, 재개할 때 현재 계약에 맞춰 검토한 테스트만 활성 위치로 복원한다.
