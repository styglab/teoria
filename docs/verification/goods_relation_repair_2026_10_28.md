# 구성 관계·작업 방향 검증 수정

2026-10-28 기존 관계 추출 단계와 최종 검증·보고서를 수정했다. 별도 업무 Flow는 만들지 않았다.
원문에 근거가 있는 item→root 구성 관계를 구매 범위와 함께 추출하고, 잘못된 관계는 재판정 후 보류한다.
수정 코드는 작업공간에 반영했으며 운영 Worker 배포·Published Ontology 게시·사전 DB 변경은 수행하지 않았다.

## 변경한 동작

1. 기존 지시는 root/items 연결을 출력하지 않도록 해 범위 관계만 남기거나 부속 납품 문서를 장비 부품으로
   잘못 연결하는 문제가 있었다. 이제 코드는 범위 관계만 생성하고, 모델은 구성 목록·구성 문장을 근거로
   component_of를 별도로 출력한다. 공급 목록·표 제목만으로 구성품을 단정하지 않는다.
2. service_for는 activity에서 출발해야 한다. 장비·소프트웨어·구성 그룹에 작업·문서를 component_of 또는
   physical_part_of로 붙이는 것도 거부한다. 물리적 포함은 명시 근거를 요구한다.
3. 잘못된 관계는 검증 오류와 함께 한 번 재판정한다. 이후에도 해결되지 않은 관계·순환·ambiguous·unknown은
   held_relations에 원래 방향·유형·근거·사유를 남긴다. 이름이나 방향을 코드가 임의로 바꾸지 않는다.
   불확실한 판단 자체에 확신을 강요해 재판정시키지는 않는다.
4. 문서의 엔티티·수량·속성은 관계 보류 때문에 삭제하지 않는다. held_relations는 최종 추출 JSON에 보존하며
   문서 상태는 partial이다. 기존 checkpoint의 잘못된 작업/구성 유형도 최종 검증에서 거부해 재추출을 요구한다.
5. 보고서에서 같은 두 대상의 범위·구성 연결은 한 항목의 [범위·구성]으로 표시한다. 보류 관계는 별도 표로 표시한다.

## 실제 4개 원본 비교

기존 HWP·PDF·HWPX 원본을 모델 gpt-6.1-sol·파서 0.9.15로 수정 전후 각각 새로 처리했다.
추출 checkpoint는 사용하지 않았다. 원문 해시·모델·Parser 실행 환경·기존 사례·채점 코드를 고정했다.

분류가 없는 기존 원본은 동일 평가 CLI의 명시적 selection_mode=fixed_sources로 실행했다.
분류/공고 근거를 만들지 않았고, 기본 분류 기반 평가의 검증은 유지했다. 이미 알려진 네 문서이며
development만 있는 고정 비교다. 신규 독립 validation 또는 fresh sample이라고 표시하지 않는다.

아래 수는 생성된 제안 관계를 정의한 유형 규칙으로 검사한 결과이며 의미 정확도·전체 재현율은 아니다.
명시·해석 근거를 모두 포함한다. 특히 차량 19개에는 1차 목록뿐 아니라 별도로 명시된 하위 장치도 포함된다.

| 문서 | 유형 규칙에 맞는 본체 구성 연결 전→후 | 작업/문서 등 유형 오류 전→후 | 수정 후 보류 |
|---|---:|---:|---:|
| 환경감시·모니터링 | 0 → 2 | 2 → 0 | 1 |
| LC-MS | 0 → 9 | 2 → 0 | 1 |
| 농기계 분석시험장치 | 1 → 10 | 0 → 0 | 56 |
| 동물이송진료 차량 | 0 → 19 | 6 → 0 | 0 |

수정 전 본체 구성으로 묶였던 사용 지침서·증명서·부품리스트 등은 문서이므로 장비 구성품으로 처리하면 안 된다.
기준 실행의 유형 오류 10건은 수정 후 실행에서 0건이다. 단순히 전체 구성 관계 수가 늘었다고 개선으로 보지 않는다.
이번 실모델 기준·수정 실행의 잘못된 service_for 출발 유형은 모두 0건이었다.
과거 역방향 문제는 통제된 회귀 테스트에서 수정 전 실패·수정 후 통과로 재현·차단했다.

농기계 문서는 10개 1차 항목 모두 원문 구성 목록을 근거로 [범위·구성]으로 연결됐다.
열화상카메라→표준 렌즈 하위 관계도 유지됐다. 56개 보류는 모호한 동일 대상 연결, 조건부 예비품·소모품·자료의
상위 대상이 불분명한 관계 등이다. 누락된 구성품이나 요구조건 56개를 뜻하지 않는다. 대상과 원문은 유지한다.

수치 예시 0.0001~10 mL/min, +1,000 ℃ 이상, 허용하중 200 kg 이상, 인버터 3 kW 이상은
전후 값·단위·연산·대상·역할·범위가 일치했다. 가스 조합의 값·연산은 같지만 대상이 센서→측정 장치로 바뀌었다.
신규 모델 추론 간 대상 표현·세분화 변동이 있으므로 모든 추출 관찰이 동일하게 보존됐다고 주장하지 않는다.

## 고정 사례와 한계

기존 silver 사례를 바꾸지 않은 정확 일치는 전후 모두 다음과 같다.

- 엔티티 1/14, 관계 1/10, 요구조건 0/4.
- 실패 문서·근거 불일치 엔티티/속성·잘못된 endpoint/근거·미귀속 속성·동일 관찰 중복은 모두 0.
- 네 문서 모두 partial이다. 형식/원문 적합성과 업무 의미의 완성은 다르다.

명칭의 병기·부모 이름·대상 세분화·관계 종류의 차이는 여전히 남는다. 이름·조건·소유 대상 판정을 느슨하게 하거나
라벨·채점기를 변경해 통과시키지 않았다. 공식 판정은 inconclusive이며, 기존 사례 점수의 개선이나
독립 일반화를 입증하지 못했다. 이번 결과는 요청한 구성·방향 규칙의 구현과 알려진 원본의 동작 확인에 한정한다.
