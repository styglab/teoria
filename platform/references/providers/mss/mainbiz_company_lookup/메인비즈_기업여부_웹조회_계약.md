# 메인비즈 기업 여부 웹 조회 계약

## 출처와 의미

- 공식 화면: `https://www.smes.go.kr/mainbiz/main.do`
- 제공기관: 중소벤처기업부
- 배포 화면: 경영혁신형 중소기업 인증시스템
- 확인일: 2026-08-06
- 계약 성격: 공식 화면이 사용하는 비로그인 HTML 조회 계약

공식 화면은 사업자등록번호(-없이) 또는 기업명으로 메인비즈 기업을 조회한다. 별도 공개
OpenAPI 명세가 아니라 공식 HTML과 JavaScript 요청 코드를 대조한 계약이므로 화면 구현
변경 시 예고 없이 바뀔 수 있다.

## Operation

- Method: `GET`
- Path: `/mainbiz/usr/main/certifiCheck.do`
- 인증: 없음
- CAPTCHA: 관측되지 않음
- 요청 파라미터: `certiCheck` (사업자등록번호 또는 기업명)
- 응답 content type: `text/html`

응답의 `table.tb-08` 본문은 다음 열을 제공한다.

| 순서 | 원본 열 | Registry 필드 | 관측 타입 |
|---:|---|---|---|
| 0 | 기업명 | `company_name` | string |
| 1 | 지역 | `region` | string |
| 2 | 유효기간 | `certification_period` | string |
| 3 | 연장기간 | `renewal_period` | string |

사업자등록번호로 검색할 수 있지만 결과 표에는 사업자등록번호가 다시 표시되지 않는다.
검색 결과가 없으면 표 본문에 `메인비즈 기업이 아닙니다.`라는 단일 셀 행을 반환한다.
이 행에는 유효기간이 없으므로 구조화 후 현재 인증으로 판정되지 않는다.

## 검증 관측과 제한

공개 기업명 검색에서 복수 레코드와 `YYYY-MM-DD ~ YYYY-MM-DD` 형식의 유효기간 및
연장기간을 확인했다. `연장기간`은 원문 명칭 그대로 보존하며 인증 유효기간으로 합산하지
않는다. 현재 인증 여부는 조회일이 `유효기간`에 포함되는지로 판단한다.
