# 프런트엔드 공통 스타일·문서 탐색 개선 — 2026-10-31

## 변경

색상·간격·글자/컨트롤 크기는 `components/ui/design_tokens.css`, 버튼은
`button.tsx`/`button.css`, 공통 입력은 `input.tsx`/`form_controls.css`를 기준으로 정리했다.
FormatID와 공통 검색 필드가 같은 컴포넌트를 사용한다. 이전 전역 `main` 표현은
구형 `.app-shell` 내부로 제한했다. 화면별 레이아웃과 기존 CSS는 남아 있으며 전면 교체한 것은 아니다.

문서 목록은 갱신 중 기존 행을 유지하고 이전 조회 조건임을 표시한다. 분류/문서 오류와 재시도를
분리하고 요청을 조건 변경·이탈 시 취소한다. 인증 만료·권한·저장소 접근·조회 한도·무결성 오류를
구분해 안내한다. 메모리 캐시는 최대 8개·30초이며 토큰 변경/세션 종료 시 비운다.
관찰 본문을 브라우저 영구 저장소에 저장하지 않는다. 목록의 스크롤과 비교 선택은 탭 메모리에서 복원한다.

모바일은 카드 목록과 접이식 필터, 대상→속성→근거 이동을 제공한다. 표준 상세는 속성·요구값/단위/조건·근거를
우선 표시하고 원문 값·식별자는 펼친다. 작은 화면의 속성 행은 세로로 배치한다.
문서 비교에는 적용 표준과 기준을 표시하고 표준·단위·범위·역할·대상 연결이 다른 빈 셀의 이유를 제공한다.

주요 업무 화면은 방문 시 코드를 적재하며, 화면 오류에는 탐색을 유지하는 복구 화면을 제공한다.
구성 목록의 엔티티·속성 수와 매핑을 반복 선형 탐색하지 않도록 인덱스를 사용한다.
1,000개 대상 샘플을 측정했으며 이번에는 가상화를 추가하지 않았다.

## 검증

- 컴포넌트/기능 테스트 24개 파일·104개 항목 통과. 요청 취소·오래된 응답 무시·오류 시 이전 결과 유지,
  인증별 캐시 격리/폐기, 비교 제외 이유와 화면 오류 복구를 포함한다.
- TypeScript·Vite 프로덕션 빌드 통과. 초기 JavaScript는 이전 약 478 kB에서 268 kB로 감소했다.
  ELK 그래프 번들은 별도 지연 적재로 유지한다. 실제 사용자 네트워크 속도를 측정한 수치는 아니다.
- 고정 Playwright 컨테이너에서 브라우저 시나리오 8개 통과. 9개 화면 기준 이미지를 생성한 뒤
  기준 갱신 없이 비교 검사를 통과했다. 실제 API/인증정보 대신 고정 샘플을 사용한다.
- 목록·입력 포커스·펼친 셀렉트·모바일 카드·상세·원문·비교, 키보드 선택, 실패 재조회,
  스크롤/선택 복원, 모바일 왕복 탐색을 검사했다. 동일 이미지·digest를 사용하는 CI job을 추가했다.
  GitHub의 실제 CI 실행 성공을 기록한 것은 아니다.
- 1,000개 대상의 고정 샘플은 초기 표시 약 0.8–0.9초, 검색 후 선택 약 0.3초였다.
  이는 두 Worker로 실행한 로컬 컨테이너의 관찰값이며 운영 데이터 전체의 성능 보장은 아니다.

## 배포

실제 데이터의 개발 미리보기에서 문서 목록·상세·근거·문서 비교와 모바일을 확인했다.
Compose `teoria`의 웹 게이트웨이만 빌드·교체한다. 최종 운영 검증과 이미지 정리 결과는 아래에 기록한다.

최종 웹 이미지 `cae81f0b31f9`를 배포하고 healthy를 확인했다. 22개 서비스가 모두 실행 중이며
healthcheck가 있는 서비스는 모두 healthy였다. 인증된 Admin API·선택 모듈 연결 검사를 통과했고,
제공된 정적 JS/CSS checksum이 검증한 로컬 빌드와 일치했다.
실제 규격서 33개·분류 2개에서 목록·상세·원문·문서 2개 비교·모바일을 확인했다.
브라우저 예외·실제 서버 5xx·검증 중 쓰기 API 요청은 각각 0건이었다.

배포된 검색창·셀렉트·데이터 자산 검색 그룹의 포커스 중복 없음, 키보드 선택,
미지원 스타일을 가정한 fallback과 고대비 모드도 확인했다. 브라우저 검사는 Chromium이며
다른 브라우저 엔진의 실환경 검증은 이번 범위에 포함하지 않았다.
문서 처리 품질이나 과거 접근 불가 산출물을 복구하는 변경은 아니다.

전체 실행/중지 컨테이너와 다른 배포 상태의 참조를 확인한 뒤, 이번 변경의 이전 웹/중간 빌드 이미지
4개를 강제 옵션 없이 삭제했다. 웹 컨테이너는 현재 버전 1개만 존재한다. 이전 이미지는 로컬
rollback 대상으로 남아 있지 않다. 최종 상태와 제거 목록은
`deploy/compose/.state/teoria/frontend_refinement_deployment.json`에 기록했다.
