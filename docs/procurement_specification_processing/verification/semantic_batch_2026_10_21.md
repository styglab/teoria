# 1회성 의미 분석 배치 재구축

2026-10-21 사용자 요청으로 기존 구성 분석·속성 사전 bootstrap 경로를 교체했다.
현재 실행 계약과 명령은 [의미 분석 배치](retired_semantic_batch.md)를 따른다.

## 정리 범위

- `composition_analysis`, `requirement_discovery`, `dictionary_draft`,
  `dictionary_review`, `dictionary_bootstrap` 모듈 5개와 전용 테스트 2개를 제거했다.
- 기존 추출·귀속·구성 분석·사전 구축의 파생 결과 디렉터리 8개를 삭제했다.
- 삭제 대상에 있던 원본·파싱·실행 기록 139개를 `semantic_corpus/retired_inputs/`에 보존했다.
- 실제 서버 표본 10건의 원본·native·파서 기록을 `semantic_corpus/`에 고정했다.
- Harness2 지원 코드·의존성 pin·기존 검색 코퍼스·경험 기록 966개 파일을
  변경 전후 SHA-256으로 대조해 동일함을 확인했다. 기존 작업 중이던 search 모듈 변경도 보존했다.

로컬 자료 기준 경로는 `.artifacts/procurement_specifications/`다.
새 배치는 `semantic_batch_2026_10_21/`, 입력 목록은
`semantic_batch_2026_10_21_request.json`이며 삭제·보존 상세는 배치의 `cleanup.json`에 있다.
과거 사전 후보는 입력에서 제외했다. 이번 표본은 기존 문서 재사용이며 독립 미사용 표본이 아니다.

## 코드 검증

새 의미 IR·배치 계약 테스트 20개가 통과했다. Pipeline 전체는
235개 통과·19개 건너뜀이며 기존 Prefect Mermaid 실행 안내 경고 1개가 있었다.
이는 코드 계약 검증이며 모델 추출·개념 통합 정확도 측정이 아니다.

원문 숫자·단위·부등호 변조, 물리 순환, 다중 관계, 관찰 불변성,
차원·predicate 매핑, 별칭 근거, 작업 요구 혼입, 검토 누락·해시 변경을 확인했다.
DB·Flow·배포·Registry는 변경하지 않았다.

## 실제 실행

실제 10건의 원본·native·OCR 비활성 파서 기록을 검증하고 입력·프롬프트를 고정했다.
문서 전체를 입력한 첫 두 자동 추출 호출이 600초 제한에 도달했고 수락된 결과가 없어
종료했다. 자식 프로세스 종료 후 CLI가 즉시 반환하지 않아 부모 프로세스도 명시적으로
종료했다. 이 실행은 `execution.json`에 incomplete로 기록했다. 이후 단계의 작업을
미리 대기시키지 않는 고정 worker·실패 시 취소 구조로 수정했다. 10건 자동 실행은
다시 완료하지 않았으며 긴 문서의 구간별 추출·병합은 후속 과제다.
수정 후 실제 Codex 호출에 1초 제한을 적용해 TimeoutError로 단계가 종료되고
CLI 프로세스가 반환하는 것을 확인했다. 의미 추출 성공 검증으로 집계하지 않는다.

대신 같은 보존본에서 실제 문서 server_07·server_09·server_10을 선택해
`semantic_pilot_2026_10_21/`에 별도 배치로 고정했다. 현재 Codex가 원문을 읽고
관찰·매핑·검토 JSON을 작성했으며 기존과 동일한 근거·구조 검사 및 새 CLI의
accept/link/integrate/review/finalize 경로로 끝까지 처리했다. 범용 자동 추출
알고리즘을 검증한 실행이 아니며 해석 작성 내역은 `author_pilot.py`, 방법은
`authorship.json`에 기록했다. 과거 사전·Harness2 정답은 입력하지 않았다.

문서가 다른 메모리 용량은 하나의 속성 의미에 연결하되 총량/모듈당 범위를 보존했다.
SSD와 HDD는 별도 개념이며 저장장치의 하위 유형으로 연결했다. 110W·HBA 32GB는
원문 그대로 보존하고 검토 지적으로 남겼다. 복합 셀의 모든 조건을 원자화했다고
주장하지 않고 partial coverage와 미해결 기록을 남겼다.

최종 파일을 현재 코드에서 재계산해 파일 내용이 바이트 단위로 같음을 확인했다.
문서 링크 검사 447개·문서 84개는 오류 0건이었으며 diff 공백 검사도 통과했다.

모든 최종 결과는 suggestion이며 사람 검토·Ontology 게시·운영 배포를 하지 않는다.
