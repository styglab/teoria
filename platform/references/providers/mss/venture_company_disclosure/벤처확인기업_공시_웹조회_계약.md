# 벤처확인기업 공시 웹 조회 계약

## 출처와 의미

- 공식 화면: `https://www.smes.go.kr/venturein/pbntc/searchVntrCmp`
- 제공기관: 중소벤처기업부 벤처확인시스템
- 확인일: 2026-08-05
- 계약 성격: 공식 공시 화면이 사용하는 웹 내부 JSON 조회 계약

공식 화면은 벤처기업육성에 관한 특별법 시행령 제18조의5에 따라 벤처확인기업 정보를
공시한다고 안내한다. 이 Source의 결과는 공식 시스템이 조회 시점에 공시 목록으로
반환한 기업을 의미한다. 상세 확인서의 유효기간 시작일과 종료일을 반환하는 계약은 아니다.

이 문서는 별도 공개된 OpenAPI 명세가 아니라 공식 화면의 HTML form, JavaScript 요청 코드와
공개 응답을 대조한 것이다. 화면 구현 변경 시 계약이 예고 없이 바뀔 수 있다.

## 검색조건

- 기업명: `cmpNm`
- 대표자명: `rprsvNm`
- 사업자번호: `bizRNo`

법인등록번호는 공시 대상 정보이지만 목록 검색 입력과 JSON 요청 파라미터에는 없다.

## Operation

- Method: `POST`
- Path: `/venturein/pbntc/searchVntrCmpAction`
- Request content type: `application/json; charset=UTF-8`
- Response content type: `application/json`
- 인증: 없음

| 요청 필드 | 관측 타입 | 의미 |
|---|---|---|
| `cmpNm` | string | 기업명 |
| `rprsvNm` | string | 대표자명 |
| `bizRNo` | string | 사업자번호 |
| `pg` | integer | 페이지 번호 |
| `pageSize` | integer | 페이지당 표시 건수 |
| `areaCd` | string | 시·도 지역 코드 |
| `sigunguAreaCd` | string | 시·군·구 지역 코드 |
| `indstyCd` | string | 업종 코드 |

응답 최상위 필드는 `RESULT`, `TOTAL_COUNT`, `NOW_PAGE`, `DATA_LIST`다. 정상 조회의
`RESULT` 값은 `SUCCESS`로 관측됐다.

| 레코드 필드 | 관측 타입 | 의미 |
|---|---|---|
| `vnia_sn` | integer | 상세 화면 연결에 사용하는 공시 내부 식별값 |
| `cmp_nm` | string | 기업명 |
| `rprsv_nm` | string | 대표자명 |
| `bizrno` | string | 사업자번호 |
| `hdofc_addr` | string | 본사주소 |
| `indsty_cd` | string | 업종 코드 |
| `indsty_nm` | string | 업종 |

2026-08-05 공개 목록의 레코드로 값을 보관하지 않고 회사명 검색과 사업자번호 정확 일치
검색을 실제 확인했다. 법인등록번호 검색은 지원되지 않는다.

## 제한

기업 상세 화면은 CAPTCHA를 요구하므로 이 Source는 CAPTCHA를 우회하지 않는다. 확인서 발급일,
유효기간과 변경사항은 반환하지 않는다. 결과는 조회 시점의 공시 목록 등재 사실로 사용하며
과거 또는 미래 기준일의 유효성을 계산하는 용도로 사용하지 않는다.
