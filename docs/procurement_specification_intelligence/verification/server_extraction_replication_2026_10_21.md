# 같은 최소 추출 방식의 서버 규격서 3건 적용

[서버 한 건 최소 추출](server_single_extraction_2026_10_21.md)과 같은 지시문·스크립트·
출력 형식으로 다른 문서 3건을 처리했다. 문서당 실제 추론 1회, 제한 시간 120초,
동시 실행 최대 2건이다. 실패 응답의 재호출·사전 매핑·Harness2 실행은 하지 않았다.

입력은 기존 개발 corpus의 HWPX·PDF·HWP 각 1건이다. 이미 사전 구축에서 읽었던 문서로,
새로운 독립 검증셋이 아니다. 문서 원본·파싱·실행 기록의 SHA-256을 확인한 뒤 기존과
같이 비어 있지 않은 원문 줄과 노드 ID를 전달했다. 지시문과 실행 스크립트가 기존
실험과 바이트 단위로 동일한지도 확인했다.

## 실행 결과

| 문서 | 형식 | 입력 문자 수 | 초 | 결과 | 대상 / 관계 / 규격·조건 |
|---|---|---:|---:|---|---|
| server_01, R26BK01720586 | HWPX | 5,413 | 120.126 | 시간 초과 | 응답 없음 |
| server_06, R26BK01768647 | PDF | 3,502 | 108.435 | 완료 | 16 / 16 / 90 |
| server_10, R26BK01777176 | HWP | 873 | 81.011 | 완료 | 20 / 20 / 57 |

모델 실행 전체 경과는 **189.722초**다. 문자 수는 전달한 줄의 텍스트 합이며 토큰 수가
아니다. 시간에는 각 문서의 추론 호출이 포함된다. 이 3건으로 입력 길이와 지연의
인과관계나 전체 정확도를 확정하지 않는다. 이전 한 건의 성공이 긴 문서까지의 안정성을
보장하지 않는다는 점은 확인했다.

## 원문 대조

완료 2건은 원문 값·명칭 존재와 참조 검사를 통과했다. 현재 Codex가 결과를 원문과
대조하고 선택 검사를 추가했다. PDF 10개, HWP 9개 선택 검사는 통과했다. PDF의 선정
기술·요구조건 원문 줄 35개, HWP의 19개는 모두 하나 이상의 규격 관찰에 연결됐다.
이것은 줄 인용 연결과 선택 검사이며 전체 원자 규격 재현율·독립 정확도가 아니다.
HWPX는 응답이 없어 의미 대조를 수행하지 못했다.

확인한 동작은 다음과 같다.

- PDF: 별도 공급·미설치 NIC를 서버 물리 장착품과 구별했다. GPU 96GB·4ea, PSU 2200W,
  OS 듀얼부트, 작업 할당 GPU 1EA/2EA/4EA, 공동사용자 최소 10인, 보고서·납품·보증
  조건을 보존했다. 미기재 PSU 수량이나 CPU 코어 수를 만들어 넣지 않았다.
- HWP: CPU 지원과 실제 CPU 2EA, 메모리 뱅크 24개와 메모리 16GB·18개, NIC 2PORT와
  OmniPath 카드 1Port·2개, 케이블 2m·2개를 구별했다. 계산한 288GB를 원문 값으로
  만들지 않았다. 베이 지원을 실제 HDD 납품으로 확정하지 않았다.

## 남은 문제

1. **시간 제한 내 처리의 불안정성**: 여러 납품 물품과 긴 소프트웨어·서비스 조건을
   포함한 HWPX는 120초 내 응답을 받지 못했다. 처리 완료로 집계하지 않는다.
2. **메모리 용량 범위 미해결**: PDF의 384GB·128GB·3ea, HWP의 16GB·18개는 보존했지만
   총량·모듈당 용량을 불명으로 남겼다. 명시 근거와 문맥 해석을 구분해 표현할 필요가 있다.
3. **장비 과분리**: HWP의 클러스터서버와 모델 UTS-Z2312 G5가 별도 대상으로 나뉘어
   납품 수량과 상세 규격이 다른 노드에 붙었다. 두 노드의 동일 장비 여부를 정리해야 한다.
4. **관계 근거 수준 부족**: 물리구성·구성규격 등 자유 표현에 명시/추론/모호성 구분이
   없다. 물리구성으로 표현한 관계를 모두 오류라고 판정한 것은 아니며, 근거 수준을
   분리하지 못하는 표현상의 한계다.
5. **텍스트 입력의 한계**: PDF의 적색 표시 조건과 이미지 내용은 현재 줄 텍스트만으로
   확인할 수 없다. HWPX·PDF에 각 1개 미확인 이미지 참조가 있다. 파싱 결과 전체를
   검토한 것으로 표시하지 않는다.

다음 수정은 이 실패와 모호성에 한정한다. 동일 장비 연결·용량 범위·관계 근거 표현을
정리하고 긴 문서 처리 범위를 검증한 뒤 사전 매핑으로 진행한다. 이번 결과로 100건
확대 준비 완료나 Harness2 고도화 완료를 선언하지 않는다.
