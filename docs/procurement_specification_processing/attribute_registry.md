# 속성 사전의 구조

현재 실행 기준은 [1회성 의미 분석 배치](verification/retired_semantic_batch.md)다.
표준 속성과 문서별 대상·조건·역할·한정자를 분리한다. 총용량과 모듈당 용량은
서로 다른 대상·집계 범위이며, 장착/지원은 관찰 한정자로 보존한다.
기본/부스트 클럭처럼 측정 의미가 다르면 속성 정의를 구분한다.

## 현재 초안의 과분리와 재검토

과거 52개·152개·189개 사전 후보와 파생 결과는 2026-10-21 사용자 요청으로
삭제했다. 해당 개수를 정제된 표준 속성 수나 새 파이프라인의 입력으로 사용하지 않는다.
새 사전은 고정한 원문 관찰에서 다시 제안하고 검토한다. 사람 승인·운영 게시는 하지 않는다.
