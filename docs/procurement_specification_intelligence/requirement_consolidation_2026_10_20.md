## 검증

원본 94개 관찰·5개 그룹·미완료 사항·검토 사유의 일치, 원본 파일 해시 불변,
모든 관찰의 귀속 제안 포함과 주요 관계를 수용 조건 12개로 확인했다.

다음 오류 주입 10건은 거부했다.

- 관찰 한 건의 귀속 제안 누락
- 유지라고 표시하면서 CPU당 범위를 시스템 전체로 변경
- 공통 납품 조건의 적용 대상을 서버만으로 임의 축소
- HDD EQ·GE 관찰을 동일 중복 후보로 변경
- 서버와 DAS PSU를 같은 범위의 충돌 후보로 변경
- 서로 다른 GPU 대안의 개수·전력 결합
- GPU 대안 관계에서 관찰 하나 누락
- 관계 근거 인용 변조
- 다른 추출 실행 ID 참조
- 승인되지 않은 우선 조건 필드 추가

반면 근거를 유지한 채 관계 설명을 잘못 작성하면 구조 검사는 통과했다.
따라서 관계의 의미적 정확성이나 조건의 완전성은 독립 검토 대상이며,
이번 자체 분석으로 Precision·Recall을 산정하지 않았다.
