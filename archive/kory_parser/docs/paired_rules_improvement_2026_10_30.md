# PDF 이중 테두리 표 복원 — 2026-10-30

**실제 개발 PDF의 15행×10열 표를 원문과 같은 9행×9열로 복원해 코드에 반영했다.**
최종 gate는 `accepted=true`, `applied=true`이며, 반영 후 전체 테스트 372개가 통과했다.
수정은 [pdf_rules.py](../src/kory_parser/pdf_rules.py), 새 회귀 테스트는
[test_pdf_paired_rules.py](../tests/test_pdf_paired_rules.py)가 소유한다.

## 결함과 변경

개발 문서 `r26bk01763991_000_03`의 2쪽에는 1.08pt 간격의 세로 이중선과
1.44pt 간격의 가로 이중선이 있다. 기존 1pt snapping은 이를 각각 다른 셀 경계로 세어
원문에 없는 빈 행·열을 만들었다. 원문 렌더와 벡터 좌표를 확인한 뒤 수정했다.

기존 snapping은 유지하고, 다음 근거가 함께 있는 경우에만 두 선을 한 경계로 합친다.

- 서로 고립된 두 선의 간격이 1.6pt 이내이고, 양쪽 선분의 시작·끝과 굵기·색상이 대응한다.
- 내부 세로 이중선이 반복된 가로 이중선 두 개 이상과 실제로 교차한다.
- 그 내부 세로선의 좌우에 전체 높이를 덮는 바깥 경계가 있다.
- 확인된 격자와 연결된 바깥 이중선도 같은 표의 경계로 처리한다.

세 개의 가까운 선을 연쇄적으로 합치거나, 다른 위치의 선·색상이나 굵기가 다른 선을
합치지 않는다. 공고번호·파일 hash·문서 문구·특정 문서 좌표로 분기하지 않는다.
PDF 엔진·의존성·옵션·기존 평가기와 정답·임계값은 변경하지 않았다.

## 검증

앞서 수집한 실제 첨부 24개와 정답을 그대로 재사용했다. 정리된 일반 성공 표본 11개는
다시 내려받아 기존 SHA-256과 일치함을 확인했다. 개발 16개·검증 8개 구성을 유지했으며,
이를 새로운 블라인드 검증이라고 주장하지 않는다. 자동 실행기의 sandbox 오류를 우회한
것이 아니라, 사용자의 직접 수정 요청에 따라 별도 후보에서 코드를 수정하고 정상 gate로
판정했다. 원래 중단 기록은 [반복 평가 기록](paired_rules_repeat_2026_10_30.md)에 남아 있다.

대상 PDF의 정규화된 문자 multiset 1,975개를 보존했다. 목표 이외 **23개 문서의 전체
출력은 동일**했고, 고정 실문서 회귀 **160개 모두** 버전 표기를 제외한 출력이 같았다.
OCR을 끈 상태에서 native 문자가 없는 검증 PDF 2개는 기존처럼 `NEEDS_OCR`을 유지했다.
참조 구현의 실행 성공을 그 문서의 본문 복원 정확도로 해석하지 않는다.

17개 새 테스트는 이중선 간격·180도 회전·셀 내용과 좌표·반복 paint·서로 다른 선분과
선 스타일·가까운 세 선·장식 프레임·단일 구분선·다른 위치의 표를 검사한다.
기존 구현에서 실제 파싱 테스트 4개가 실패했고, 후보에서 새 테스트 17개가 모두 통과했다.
반영 후 전체 **372개 통과**, 수정 파일의 Ruff·형식 검사도 통과했다.
자체 작성 2행×2열 PDF와 독립 문단의 완전한 출력 정답 평가도 모두 통과했다.

warm-up 1회와 3회 측정의 중앙값을 비교했으며, 파일 읽기와 프로세스 시작은 제외했다.
공통 성공 문서의 시간 합은 이 실행에서 약 6.24% 감소했고 지연 경고는 없었다.
이는 해당 표본과 공유 호스트에서의 측정이며 일반적인 속도 향상을 보장하지 않는다.
원문 부분 검사와 참조 구현의 일치는 전체 문서 정확도를 뜻하지 않는다.

## 적용 범위와 남은 사례

첫 후보는 고정 문서 3개의 출력도 바꿔 그대로 적용하지 않았다. 가로·세로 교차와 반복
경계의 근거를 보완한 최종 후보에서는 160개 전부의 기존 출력을 보존했다.
초기 변경 결과와 첫 후보의 소스 hash가 일치하는 snapshot도 보존했다.

반복 근거가 부족한 단일 행·장식 테두리는 기존 처리를 유지한다. 대상 PDF 3쪽의
단일 행 이어지는 표는 원문이 1×2지만 기존 2×3 결과를 유지하며 후속 검토로 남겼다.
첫 후보에서 이 표도 복원됐으나, 최종 적용은 기존 문서의 출력 보존 조건을 만족하는
확인 범위로 제한했다. 이 제한을 전체 이중 테두리 문제의 해결로 과장하지 않는다.
