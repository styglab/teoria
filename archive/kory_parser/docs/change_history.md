# Kory Parser 변경 이력

실제 적용한 파서 업데이트를 최신 버전부터 기록한다. 각 항목에는 날짜, 문제와 바뀐 동작,
검증·비교 결과, 제한과 배포 상태를 남긴다. 새 수정이 없는 평가 실행은 버전을 올리거나
새 릴리스 항목을 만들지 않고 해당 사이클의 최종 보고서에 기록한다.

## 0.9.16 — 2026-11-01

- XLSX의 셀 밖 텍스트 상자와 그룹 도형에 있는 텍스트 누락을 복구했다. 셀 값과 격자는
  유지하고 도형 텍스트는 별도 문단으로 제공하며, 원본 DrawingML part와 shape ID를 남긴다.
- 셀 내용 없이 도형 텍스트만 있는 시트도 읽는다. 숨긴 도형·그룹은 제외하고 외부 도형
  링크는 가져오지 않는다. 줄바꿈·문단 순서와 중첩 제한을 검증한다.
- 새 회귀 테스트 9개를 포함한 381개 테스트가 통과했다. 가구 규격서의 원문 도형 텍스트
  점검은 기존 Kory·kordoc의 2/6에서 6/6으로 개선됐고 기존 셀 값 736개는 모두 보존했다.
- 최초 비교는 실제 문서 22개에서 진행했다. 고정 회귀 160개 중 1개에 표지 제목과 도형
  문단 3개가 추가돼 자동 게이트는 출력 동일성 조건으로 거절했다. 기존 블록 삭제가 없음을
  확인한 뒤 사용자의 명시적인 반영 지시로 적용했다. 기존 거절 기록은 그대로 보존했다.
- wheel·소스 배포본을 빌드했고, 별도 배포 요청에 따라 로컬 규격서 Worker에 설치했다.
  실행 컨테이너의 버전과 실제 XLSX 파싱을 확인했다. PyPI 게시와 원격 운영 배포는 하지 않았다.
- 전체 형식의 품질 우위나 OCR 개선을 뜻하지 않는다. 후속 18개 문서 평가는 새 코드 변경이
  없어 같은 버전을 유지했다. 비교 요약과 판정·hash는 로컬 사이클 보고서에 보존한다.
